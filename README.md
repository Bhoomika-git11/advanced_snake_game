# 🐍 Advanced Snake Game (Python + Tkinter)

A modern, feature-rich Snake Game built using Python and Tkinter with smooth animations, particle effects, difficulty levels, and an interactive UI.

---

## 🚀 Features

- 🎮 Multiple Difficulty Modes (Easy, Medium, Hard)
- ⚡ Dynamic Speed Scaling based on level and snake size
- ✨ Particle Effects on food consumption and level-up
- 🌟 Special Food with bonus scoring
- 🧠 Smart Game Logic with smooth controls
- 📊 Live HUD (Score, Level, Speed, Best Score)
- ⏸ Pause/Resume functionality
- 🎨 Modern UI with animations and visual effects
- 🏆 High Score Tracking using JSON storage

---

## 🛠 Tech Stack

- Python
- Tkinter (GUI)
- JSON (for storing high score)
